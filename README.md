# Image Gallery

A responsive image gallery built with React. Photos are displayed as cards in a clean grid, each with a title and a short description. The layout adapts automatically to desktop, tablet, and mobile screens.


## Features

- Responsive card grid that adjusts to any screen size
- Image, title, and description on every card
- Rounded cards with soft shadows for a clean look
- Reusable gallery component driven by a simple data array
- Fast development setup

## Tech Stack

- React
- HTML5 & CSS3 (Flexbox / CSS Grid)
- JavaScript (ES6+)

## Getting Started

### Prerequisites

- Node.js
- npm (comes with Node.js)
